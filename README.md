# News Explorer (Frontend)

🔗 **Enlace a la aplicación desplegada:** [https://zesty-kangaroo-a0d7db.netlify.app/](https://zesty-kangaroo-a0d7db.netlify.app/)

## 📖 Descripción
News Explorer es una aplicación web que permite buscar noticias de todo el mundo utilizando una API de terceros y guardar los artículos favoritos en una cuenta personal. Este repositorio contiene el código del frontend del proyecto final de Practicum.

## 🛠️ Tecnologías utilizadas
- React.js
- React Router DOM
- Vite
- HTML5, CSS3 (Flexbox, Grid, Diseño Responsivo)
- JavaScript (ES6+, Fetch API)

## ✨ Funcionalidades
- Búsqueda de noticias en tiempo real mediante la API de NewsAPI (a través de proxy).
- Visualización de resultados en tarjetas responsivas (3 columnas en escritorio, 1 en móvil).
- Paginación dinámica con botón "Ver más".
- Manejo de estados de carga (preloader) y mensajes de error.
- Diseño 100% responsivo adaptado a dispositivos móviles, tablets y escritorio.
- Interfaz de usuario para autenticación (Login y Registro) con validación de formularios.

## 💻 Instalación y ejecución local
1. Clona este repositorio:
   ```bash
   git clone https://github.com/wilsonwilsoon81-sudo/news-explorer-frontend.git
   ```
2. Instala las dependencias:
   ```bash
   npm install
   ```
3. Inicia el servidor de desarrollo:
   ```bash
   npm run dev
   ```
4. Abre tu navegador en http://localhost:5173/

## 🚀 Despliegue
La aplicación está desplegada en Netlify. Para actualizar la versión en producción:
Ejecutar npm run build
Subir la carpeta dist generada a Netlify Drop.
